Bitcoin Price Tracker
A real-time Bitcoin price tracking application with beautiful charts and statistics.

Features
📊 Real-time Price Charts - View Bitcoin price trends over customizable time periods
💱 Multi-Currency Support - Track prices in USD, EUR, GBP, and JPY
📈 Market Statistics - Current price, 24h change, high, and low
🎨 Beautiful UI - Modern gradient design with responsive layout
🔄 Live Updates - Refresh button to get the latest data
📱 Mobile Friendly - Works seamlessly on all devices

Getting Started
Open index.html in a web browser
The tracker will automatically load Bitcoin price data
Use the currency buttons to switch between different currencies
Use the time period buttons to view different chart ranges
Click the refresh button to get the latest data

API
This application uses the free CoinGecko API (https://www.coingecko.com/en/api) which doesn't require authentication.
